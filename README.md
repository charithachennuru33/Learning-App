# Learning-App

Ram Intellect learning platform.

- [`platform-infra/`](platform-infra): Spring Boot backend (phone-OTP auth, tokens, SMS, payments)
- [`mobile_app/`](mobile_app): Flutter app for Android and iOS

**Getting started:** follow [SETUP.md](SETUP.md), which covers installing the tools, running the
backend, and running the app on Android emulators, iOS simulators and real devices.
